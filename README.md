# 长线价值增强项目

一个基于 XGBoost 的美股长线低频量化交易系统，用于验证「技术指标 + 新闻情绪」对股价中期（5 天）涨跌方向的预测能力。

> ⚠️ 这是一个**学习与验证型项目**，非盈利策略。核心结论见文末「回测结论」。

## 核心架构

```
数据更新 → 情绪分析(FinGPT/DeepSeek) → 决策模块(XGBoost) → 交易模块(风控) → 长任务守护进程
```

模块完全解耦，各自独立可测：

| 模块 | 职责 |
|---|---|
| `数据更新.py` | 拉取行情 + 计算技术指标（MA/RSI/MACD/成交量） |
| `情绪分析.py` | FinGPT 本地模型分析新闻情绪，DeepSeek 兜底 |
| `决策模块.py` | XGBoost 预测未来 N 天涨跌概率 |
| `交易模块.py` | 止盈止损风控 + 底仓管理 + 分批建仓 |
| `长任务.py` | 常驻守护进程：定期决策 + 盘中巡检 |
| `GDELT回填.py` | 用 GDELT 2.0 批量回填历史新闻情绪 |
| `历史情绪回填.py` | Finhub + FinGPT 回填真实历史情绪 |

## 技术栈

- **Python 3.13** / XGBoost / pandas / requests
- **情绪引擎**：本地 Ollama FinGPT（金融垂直 LLM）+ DeepSeek API 兜底
- **数据源**：AkShare、Alpaca（Paper Trading）、Finnhub、GDELT 2.0、Alpha Vantage
- **交易**：Alpaca 模拟盘（Paper Trading）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥
cp .env.example .env
# 编辑 .env，填入你自己的 Alpaca / DeepSeek / Finnhub key

# 3. 跑一轮完整决策
python main.py

# 4. 或启动常驻守护进程
python 长任务.py
```

## 风控策略

- **止损**：持仓浮亏达阈值（默认 5%）全卖
- **移动止盈**：浮盈达激活线后，从最高点回撤阈值（默认 5%）分批止盈
- **分批建仓**：按模型上涨概率分档（满仓/半仓/轻仓）

## 回测结论（重要）

本项目最重要的产出不是策略，而是**一组严谨的对照实验结论**：

1. **新闻情绪对「5 天涨跌方向预测」是负贡献**。三组独立实验（FinGPT 201 天、GDELT 364 天、纯真实情绪 450 天）一致显示：加入情绪特征后，预测胜率下降 1.8~6.6 个百分点。
2. **纯技术指标模型同样跑不赢「买入持有」基准**。这说明「预测短期涨跌方向」这件事本身，在可获取的信息下接近随机。
3. **教训**：情绪数据是滞后的镜像（反映已发生的涨跌），模型易把「相关性」误当「因果」；且 GDELT 等通用关键词抓取会混入大量与股价无关的噪音。

详见代码中的实验记录和 `项目说明.md`。
